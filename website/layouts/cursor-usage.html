Sync from Cursor

One-time setup. On cursor.com/dashboard/spending, click the bookmark to read Current Plan, Included in Pro, and Grok Bot into the fields below.

  1. Click Copy bookmarklet.
  2. Add a bookmark (⌘D / CtrlD → Edit, or right-click the bar → Add page).
  3. Name it JoRap: sync Cursor usage.
  4. Paste into the bookmark URL field — not the address bar.
  5. Save, then click it on the spending page.
Drag to bar

Desktop Chrome, Firefox, Edge, or Safari. Phones usually block bookmarklets — type fields by hand there.
